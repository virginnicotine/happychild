# Совместимый раздел «Горки» для старого статического сайта

Этот пакет адаптирует каталог ГСР-1.01, ГСР-1.03 и ГСР-1.04 к существующему HTML/JS сайту и его зелёному стилю.

## Важно
- Не объединяйте ветки и не запускайте публикацию до применения и проверки файлов.
- Сначала переключитесь на `feature/slides-section`.
- Скрипт `copy-slide-assets.sh` копирует уже подготовленные спецификации, изображения и Excel из `public/` в `src/`, потому что SourceCraft собирает `site/` копированием `src/`.
- Не копируйте `src/app` и не удаляйте существующие файлы Next.js.

## Применение из корня репозитория (Git Bash)
1. Распакуйте архив во временную папку.
2. Переключитесь на ветку:
   `git switch feature/slides-section`
3. Выполните `bash /путь/к/распакованной-папке/copy-slide-assets.sh`
4. Скопируйте файлы из архива в `src/` с заменой одноимённых файлов:
   - `products.js` -> `src/products.js`
   - `script.js` -> `src/script.js`
   - `render-spec.js` -> `src/render-spec.js`
   - `slides.html` -> `src/slides.html`
   - `slide-1.01.html`, `slide-1.03.html`, `slide-1.04.html` -> `src/`
   - `playgrounds.html` -> `src/playgrounds.html`
   - `site-enhancements.css` -> `src/site-enhancements.css`
5. Проверьте, что `src/data/slides/spec-1.01.json`, `src/slides/1.01/cover.png` и `src/downloads/specifications/ГСР-1.01.xlsx` существуют.
6. Проверьте изменения:
   `git status`
   `git diff --check`
7. Затем проверьте сборку/публикацию в отдельной ветке. Не вливайте в `main`, пока не проверены страницы `slides.html` и `slide-1.01.html`.

## Что содержит пакет
- обновлённый `products.js` — регистрирует три горки;
- обновлённый `script.js` — отображает и ищет каталог горок;
- обновлённый `render-spec.js` — поддерживает JSON со сгруппированными `records` и старые спецификации городков;
- `slides.html` и три технические карточки;
- ссылку между каталогами городков и горок;
- CSS для переключения каталогов.

## Ограничение
Пакет содержит изменённые исходники. Данные JSON, картинки и Excel не дублируются в ZIP: скрипт переносит уже существующие файлы из `public/` в `src/`.
