СЧАСТЛИВЫЙ РЕБЁНОК — ОБЪЕДИНЁННЫЙ ПАКЕТ ИЗМЕНЕНИЙ

Этот ZIP содержит файлы двух предыдущих обновлений в одном комплекте: изменения интерфейса, группировки деталей, просмотра PDF + тестовую интеграцию Supabase.
Это пакет ТОЛЬКО изменённых и новых файлов, не полная копия сайта. Оригинальные изображения, PDF и чертежи остаются в вашем репозитории.

КАК ИСПОЛЬЗОВАТЬ
1. Сделайте резервную копию папки репозитория, в которой находится .git.
2. Распакуйте архив. Скопируйте СОДЕРЖИМОЕ папки factory-system в корень своего проекта с сохранением вложенных путей (только если HTML файлы лежат в корне репозитория). НЕ создавайте дополнительный вложенный уровень factory-system, если его раньше не было.
3. Не копируйте и не удаляйте папку .git.
4. Удалите устаревший netlify.toml ВРУЧНУЮ, если он остался в репозитории.
5. Контакты для ссылки «Столкнулись с проблемой?» впишите в site-contacts.js (phone и website вместо «—»).
6. Серверный код Edge Function находится в supabase/functions/site-api/index.ts, его необходимо развернуть В SUPABASE, не достаточно положить в репозиторий. См. ИНСТРУКЦИЯ-SUPABASE.txt.
7. Не выполняйте git push и не обновляйте действующий сайт, пока отдельно не развернёте и не протестируете функцию, регистрацию, вход и права.

ЧТО ОБЪЕДИНЕНО
• Убраны декоративные эмодзи в обработанных файлах, изменён блок помощи на входе.
• Обновлена группировка горок (разные горки отдельно), площадок/полов и зеркальных деталей в script.js; для проверки точности просмотрите реальные изделия.
• Модуль предпросмотра PDF: pdf-preview.js + site-enhancements.css.
• Supabase: supabase-config.js, supabase-client.js, supabase-login.js, supabase-gate.js, supabase-admin.js, файлы Edge Function.

ОГРАНИЧЕНИЯ ТЕСТОВОЙ ВЕРСИИ
• Регистрация, Edge Function и права НЕ проверялись на живом Supabase и Yandex/SourceCraft.
• Старые локальные жалобы не синхронизированы автоматически; статические документы доступны по прямым ссылкам.
• Публичный вход по логину требует ограничения попыток входа (rate limit), прежде чем выпускать в продакшен.
• Миграция локальных аккаунтов работает лишь при сохранении данных в прежнем браузере; в сложных случаях нужен администратор.
• Прежде чем публиковать, проверьте визуально и функционально каталог, группировку, PDF, вход, блокировки и права.
